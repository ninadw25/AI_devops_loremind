# Slack Test Data Generator

This repository contains a Python script that generates realistic Slack test data with AWS Bedrock and posts it to Slack via the Web API.

## What it does

- Creates test channels when possible
- Posts realistic messages generated by Bedrock
- Adds thread replies, reactions, edits, and deletes
- Supports DeepSeek Bedrock models with the current response parser

## Requirements

- Python 3.10+
- AWS credentials with Bedrock access
- A Slack bot token with write permissions

## Install

```bash
pip install boto3 requests
```

## Run

```bash
python scripts/generate_slack_test_data.py \
  --slack-token xoxb-your-token \
  --bedrock-model deepseek.v3.2 \
  --num-messages 200
```
